# What was verified, and where

Honest status. "Verified" means observed directly; "not confirmed" means not yet tested. Please open an issue
with your PolyScope version and results to extend this table.

|---|---|---|
| `.urp` is gzip-compressed XML | verified (many programs) | not checked |
| Node types, `Script` node cache, `Contributed` URCap nodes (read) | verified | not checked |

| Generated `.script` holds `global FEATURE=p[...]` and `<wp>_p` poses | verified | not checked |
| `crcValue` is shared across programs, not a content hash | verified | not checked |

| Dashboard `PolyscopeVersion` / read-only queries | verified | verified |

| A program edited or generated by these scripts **opens in PolyScope** | **not confirmed** | **not confirmed** |
| A generated program runs and moves as intended | **not confirmed** | **not confirmed** |
| Uncompressed `.urp` accepted | not tested | not tested |
